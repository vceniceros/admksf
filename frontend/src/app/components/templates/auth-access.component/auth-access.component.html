Consorcio 360

Acceso administrativo para operar liquidaciones, pagos y gestión del consorcio.

El frontend se conecta con el backend Django para autenticar usuarios, obtener el JWT y sostener la sesión protegida antes de entrar al menú de consorcios.

JWT backend Sesión firmada y validada por la API.
Registro directo Alta de administradores desde la misma pantalla.
Estructura atómica Átomos, moléculas, organismos y template alineados al proyecto.
